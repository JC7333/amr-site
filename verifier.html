Vérifier un mandat

Avant d'accepter ce que demande un agent, on vérifie qui l'a autorisé et dans quelles limites, comme on vérifie un Kbis avant de signer avec une société. Essayez sur le registre de démonstration. Rien n'est envoyé, votre navigateur fait le contrôle.

Cette démonstration a besoin de JavaScript. Sans lui, les deux fichiers se vérifient à la main, avec les commandes données plus bas.

Essayer avec

Ce que votre navigateur vient de faire

  1. Il a lu deux fichiers de ce site : un instantané signé du registre de démonstration, et la clé publique de ce registre.
  2. Il a contrôlé la signature de l'instantané avec cette clé. Un seul caractère changé, et la signature ne tient plus.
  3. Il a cherché le mandat, puis appliqué la règle du registre. Un mandat est actif s'il n'est ni retiré ni expiré, et si tous les mandats au-dessus de lui tiennent aussi.
  4. Il a calculé l'empreinte de l'identifiant que le mandant annonce, et l'a comparée à celle que publie le registre.

Ce que l'instantané ne dit pas

  • Il date du 13/11/2026. Un retrait fait après cette date n'y figure pas.
  • Le nom du mandant n'y figure pas, seulement une empreinte de son identifiant. Celui à qui le mandant a donné cet identifiant recalcule l'empreinte et compare, comme le fait cette page. Le texte du mandat, les actes journalisés et les contestations ne sont pas publiés.
  • « Signé par le mandant » veut dire signé avec la clé qu'il a enregistrée. Pour un identifiant ordinaire, le registre ne vérifie pas qui tient cette clé, ni le pouvoir de cette personne dans son organisation.
  • Se fier à une clé publique, c'est se fier à celui qui la publie. Ici, c'est ce site, pour un registre de démonstration.
  • Tout est fictif. Les organisations et les agents de cette démonstration n'existent pas.

Le refaire sans ce site

Les mêmes fichiers, vérifiés par le code d'AMR sur votre machine.

curl -O https://www.mandatia.eu/assets/demo/registry-snapshot.jws
curl -O https://www.mandatia.eu/assets/demo/registry-key.pem
pip install mandatia
python -m amr.public_registry serve --export registry-snapshot.jws --public-key registry-key.pem

Ouvrez ensuite http://127.0.0.1:8080/.

Le format est décrit dans la spécification du registre public. Les données ont été produites par le code d'AMR le 13/11/2026, avec ce script.

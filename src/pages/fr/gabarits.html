Gabarits de mandat

Un gabarit est un mandat type pour un métier, écrit dans le code d'AMR. Il dit ce que l'agent peut faire, ce qu'il ne peut jamais faire, ses plafonds et sa durée par défaut. Vous partez de là.

Chaque gabarit liste aussi les textes que le mandant doit vérifier. Ils restent marqués « à vérifier » tant que personne ne les a vérifiés. Un mandat construit sur un gabarit garde sa version et son empreinte SHA-256.

Chaque gabarit est un socle provisoire. Le registre AMR le tient jusqu'à ce qu'un organisme du secteur le reprenne, et aucune relecture par des praticiens n'est encore enregistrée. Les gabarits sont une API Python du code d'AMR. Aucun outil MCP ne les liste encore.

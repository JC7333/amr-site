Verify a mandate

Before accepting what an agent asks for, you check who authorized it and within what limits, the way you check a company register extract before signing with a company. Try it on the demonstration registry. Nothing is sent, your browser does the check.

This demonstration needs JavaScript. Without it, both files can be checked by hand, with the commands given below.

Try with

What your browser just did

  1. It read two files from this site: a signed snapshot of the demonstration registry, and the public key of that registry.
  2. It checked the signature of the snapshot with that key. Change a single character, and the signature no longer holds.
  3. It looked up the mandate, then applied the registry's rule. A mandate is active if it is neither revoked nor expired, and if every mandate above it holds too.
  4. It computed the fingerprint of the identifier the principal announces, and compared it with the one the registry publishes.

What the snapshot does not say

  • It dates from {{f:demo_date_en}}. A revocation made after that date is not in it.
  • The principal's name is not in it, only a fingerprint of its identifier. Whoever was given that identifier by the principal recomputes the fingerprint and compares, as this page does. The text of the mandate, the logged actions and the contests are not published.
  • “Signed by the principal” means signed with the key it registered. For an ordinary identifier, the registry does not check who holds that key, nor that person's power within their organization.
  • Trusting a public key means trusting whoever publishes it. Here, that is this site, for a demonstration registry.
  • Everything is fictional. The organizations and agents of this demonstration do not exist.

Do it again without this site

The same files, checked by the AMR code on your machine.

curl -O https://www.mandatia.eu/assets/demo/registry-snapshot.jws
curl -O https://www.mandatia.eu/assets/demo/registry-key.pem
pip install mandatia
python -m amr.public_registry serve --export registry-snapshot.jws --public-key registry-key.pem

Then open http://127.0.0.1:8080/.

The format is described in the public registry specification. The data was produced by the AMR code on {{f:demo_date_en}}, with this script.
